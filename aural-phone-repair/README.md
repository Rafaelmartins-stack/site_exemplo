# AURAL // Hardware Lab

Site de assistência técnica e boutique, com um visualizador 3D interativo de iPhone 14 Pro.

## Modelo 3D

- Arquivo usado: `assets/iphone-14-pro.glb`
- O celular inclina levemente conforme o cursor se move pela área 3D.
- Clique, segure e arraste para girar o aparelho livremente e visualizar a traseira.
- Não há animação de desmontagem, slider ou controles de componentes internos.

## Como abrir

O arquivo `.glb` deve ser servido por um servidor local. Não abra o `index.html` com dois cliques.

No PowerShell, dentro desta pasta, execute:

```powershell
.\serve.ps1
```

Depois abra [http://localhost:3000/](http://localhost:3000/) no Chrome.
